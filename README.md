# Shape Sculptor

Quero construir uma pagina interativa, onde vamos falar de grupos musculares e organização de treino. Precisa ter modelos 3D de homens e mulheres com possibilidade de tirar a skin e mostrar a musculatura, vamos escolher o exercicio e mostrar os musculos atingidos com o exercicio. nos exemplos, vamos escolher o modelo, selecionar altura peso e BF, após isso selecionamos a rotina de treino do boneco e desenvolvemos uma rotina, a cada semana vamos avaliar a melhora no shape do boneco, de acordo com o que foi treinado (vamos ter um bonus de edição de dieta, mas será pago pra pessoa colocar essa variavel), no modelo free é só o exercicio.

No exemplo, se eu pego um homem e adiciono treino de ombro dele dia sim dia não, ele vai desenvolver apenas essa musculatura e os adijacentes. Tbm teremos uma feature bonus de saúde, rompimento muscular se treinar muito, up se adicionarmos ergogenicos e hormonios com buff de recuperação etc...)

Design limpo futurista, estilo apple. branco, bordas modernas, fontes bonitas, etc...

Seja ousado visualmente. Preciso poder escolher os músculos e os exercícios, com variações de máquinas, pesos livres e cabos.
